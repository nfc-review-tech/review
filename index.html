Условия размещения данных

Подтверждаю, что имею право предоставить название, ссылки и контакты организации для её публичной страницы NFC-стикера. Размещённые сведения можно обновить или удалить по запросу продавцу.

Как обрабатываются данные заявки

Заявка отправляется через FormSubmit на электронную почту продавца. После проверки сведения о компании добавляются в открытый файл clients.json на GitHub Pages. Телефон, email или аккаунт мессенджера, если указаны, станут публичными. Не указывайте личные данные третьих лиц без необходимого разрешения.

Для изменения или удаления данных свяжитесь с продавцом в переписке по заказу.

Спасибо! Заявка отправлена продавцу.

Ожидает активации

Стикер будет подключён после проверки данных продавцом. Это может занять некоторое время. Повторно отправлять заявку не нужно.

Когда стикер активируют, просто приложите к нему телефон ещё раз. Перепрограммировать метку не потребуется.
