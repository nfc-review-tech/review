Без Supabase · работа напрямую с GitHub

Быстрая активация NFC-стикеров

Больше не нужно скачивать, объединять и загружать clients.json. Вставь запись из письма и нажми «Активировать».

1. Доступ к GitHub

Внимание: репозиторий принадлежит организации. В настройках Fine-grained token обязательно выбери Resource owner: nfc-review-tech (не свой личный аккаунт), Repository access: Only select repositories → review, Contents: Read and write. Если GitHub показывает статус Pending, администратор организации должен подтвердить токен.

Проверить настройки токена

Токен не сохраняется ни в этом файле, ни в браузере. Он отправляется только на api.github.com. Никому его не пересылай.

Эта проверка ничего не изменяет в clients.json. Право записи проверится только при активации.

2. Вставь запись клиента из письма

Скопируй целиком поле «Готовая запись для clients.json», начиная с { и заканчивая }. Для нескольких заявок вставь их одну за другой — каждая отдельным JSON-блоком.

Новые заявки:

    Сейчас изменений нет. Сначала вставь запись из письма.

    Что происходит после нажатия?

    Утилита получает последнюю версию clients.json, добавляет только новые ID и отправляет один коммит в GitHub. Старые клиенты сохраняются. Если другой редактор успел обновить файл, утилита перечитает его и попробует объединить изменения без потери записей.

    Если такой ID уже существует, повторная активация блокируется. Обновление данных существующих клиентов здесь намеренно выключено.

    Посмотреть действующий clients.json · Открыть сайт стикеров

    Важно: работающий сайт и физические метки не изменяются. Новые данные становятся доступны после публикации обновлённого GitHub Pages. Проверяй страницу нового клиента перед тем, как сообщить ему об активации.
